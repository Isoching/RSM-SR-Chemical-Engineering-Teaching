# Response Surface Methodology and Symbolic Regression for Chemical Engineering

Four worked teaching notebooks introduce response surface methodology (RSM) and symbolic regression (SR) through chemical engineering examples. The [teaching notes](NOTE.md) explain the learning sequence, each case, how to run the notebooks, and the scope of the accompanying guide and slides.

| Order | Material | Topic |
| --- | --- | --- |
| 1 | [Batch esterification](01_RSM_Batch_Esterification.ipynb) | RSM for yield and operating point selection |
| 2 | [Selective CSTR](02_RSM_Selective_CSTR.ipynb) | RSM for yield–productivity trade-offs |
| 3 | [Pipe pressure loss](03_SR_Pipe_Pressure_Loss.ipynb) | Restricted symbolic search for pressure-loss scaling |
| 4 | [Humid CO₂ adsorption](04_SR_Humid_CO2_Adsorption.ipynb) | Structured symbolic search for equilibrium and uptake |

The repository also contains a [modelling guide](RSM_SR_Chemical_Engineering_Modelling_Guide.docx) and a [symbolic regression lecture deck](Symbolic_Regression_Chemical_Engineering_Teaching.pptx).

The notebook data are synthetic teaching examples, not laboratory measurements or validated plant predictions. See [NOTE.md](NOTE.md) before reusing a fitted relation.
